== asset:image

=== Description

Creates an `<img>` element, e.g. `<asset:image src="example/foo.png" absolute="true"/>`
Any attributes other than those described below will be forwarded to the `<img>` element generated by this tag.

=== Attributes

[cols="1,1,2"]
|===
| Name
| Required
| Description

| src
| Yes
| Path to the image file

| absolute
| No
| If truthy, an absolute URL will be used for the `src` attribute of the generated `<img>` element. By default, a relative URL is used.
|===
