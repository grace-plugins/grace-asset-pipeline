== asset:stylesheet

=== Description

Include a CSS file in a page, e.g. `<asset:stylesheet href="example/style.css"/>`. Any attributes other than those
described below will be forwarded to the `<style>` element generated by this tag.

=== Attributes

[cols="1,1,2"]
|===
| Name
| Required
| Description

| src
| if `href` is not provided
| Path to the CSS file

| href
| if `src` is not provided
| An alias for `src`

| charset
| No
| The file's character set
|===
