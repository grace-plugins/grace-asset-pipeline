== asset:link

=== Description

Generates a `<link>` element for an asset, e.g.
`<asset:link rel="shortcut icon" type="image/x-icon" href="favicon.ico"/>`
Any attributes other than those described below will be forwarded to the `<link>` element generated by this tag.

=== Attributes

[cols="1,1,2"]
|===
| Name
| Required
| Description

| href
| Yes
| Path to the asset

| rel
| No
| The value of the `rel` attribute of the generated `<link>` element

| type
| No
| The value of the `type` attribute of the generated `<link>` element
|===
